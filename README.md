# Chandrashu Portfolio

A clean single-page full-stack developer portfolio built with HTML, CSS, and JavaScript.

## Sections

- Hero with clear developer positioning
- Featured WanderHome project
- Project highlights
- Skills and process
- Contact links

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static server.

```bash
python -m http.server 5501
```

Then visit `http://localhost:5501`.

## Files

- `index.html` - page content and structure
- `style.css` - responsive visual design
- `script.js` - navigation and reveal interactions
- `assets/` - portfolio images
